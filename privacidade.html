Política de Privacidade

Última atualização: 20 de setembro de 2026.

Projeto demonstrativo: este site foi criado para portfólio e não representa uma empresa real.

Dados enviados pelo visitante

O site não possui cadastro, login ou formulário que envie dados pessoais para um servidor. Os botões de orçamento são apenas demonstrativos.

Cookies e análise de navegação

Este projeto utiliza o Microsoft Clarity para compreender, de forma agregada, como os visitantes interagem com as páginas, incluindo cliques, rolagem e navegação. Essas informações ajudam a avaliar e melhorar a experiência do site.

O Clarity recebe um sinal de consentimento por meio da API Consent V2. Cookies e armazenamento analítico somente são autorizados depois que o visitante escolhe “Aceitar”. A escolha fica salva neste navegador e pode ser alterada a qualquer momento pelo botão “Rever escolha de privacidade” abaixo.

Para saber como a Microsoft trata os dados coletados pelo Clarity, consulte a Declaração de Privacidade da Microsoft.

Hospedagem

O projeto é publicado pelo GitHub Pages. Como em qualquer hospedagem web, o provedor pode processar dados técnicos necessários à entrega e segurança do serviço de acordo com suas próprias políticas.

Contato

Os dados comerciais exibidos na landing page são ilustrativos. Para informações sobre este projeto de portfólio, utilize os canais profissionais do autor apresentados em seu portfólio principal.
