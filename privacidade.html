Política de Privacidade

Última atualização: 19 de setembro de 2026.

Projeto demonstrativo: este site foi criado para portfólio e não representa uma empresa real.

Dados enviados pelo visitante

O site não possui cadastro, login ou formulário que envie dados pessoais para um servidor. Os botões de orçamento são apenas demonstrativos.

Cookies e análise de navegação

Neste momento, nenhuma ferramenta de análise de navegação está ativa neste projeto e o site não solicita consentimento para cookies analíticos.

Se uma ferramenta de análise, como o Microsoft Clarity, for adicionada posteriormente, o projeto será atualizado para informar seu uso e oferecer os controles apropriados antes da ativação de cookies de análise.

Hospedagem

O projeto é publicado pelo GitHub Pages. Como em qualquer hospedagem web, o provedor pode processar dados técnicos necessários à entrega e segurança do serviço de acordo com suas próprias políticas.

Contato

Os dados comerciais exibidos na landing page são ilustrativos. Para informações sobre este projeto de portfólio, utilize os canais profissionais do autor apresentados em seu portfólio principal.
